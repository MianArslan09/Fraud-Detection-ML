# Fraud-Detection-ML
# 💳 Credit Card Fraud Detection App

An interactive **Streamlit** web application that detects credit card fraud using machine learning models. Upload your CSV dataset, preprocess data, apply PCA, train models like Logistic Regression, Random Forest, or XGBoost, and predict fraudulent transactions in real-time.

---

## 🚀 Features

- 📂 Upload custom CSV datasets
- 🧹 Data preprocessing (missing value & duplicate removal, scaling)
- 📊 Principal Component Analysis (PCA) visualization
- 🧠 Model training (Logistic Regression, Random Forest, XGBoost)
- 🔍 Hyperparameter tuning using Grid Search
- 📈 Performance metrics: Accuracy, Precision, Recall, F1 Score
- 🧾 Confusion matrix visualization
- 💰 Total fraud amount calculation
- ⚡ Real-time row-wise fraud prediction
